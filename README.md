# Developer Portfolio — Joakim Silva

My personal developer portfolio and CV website, built from scratch using HTML, CSS and JavaScript.

The website showcases my software development projects, technical skills, education and professional experience.

## Live Website

[View Developer Portfolio](https://joakim-silva.github.io/)

## Features

* Responsive desktop and mobile layout
* Mobile navigation menu
* Dynamic navigation highlighting based on the section currently in view
* Smooth scrolling
* Interactive Back to Top button
* Project showcase
* Technical skills section
* Education and professional experience
* Contact and social links
* Links to project source code

Clone the repository:

```bash

```

Then open `index.html` in a web browser.

No installation or build process is required.
